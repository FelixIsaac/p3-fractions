   - Call onAnimationComplete after animation finishes

- Start with original segments (e.g., 3 segments for /3)
- Animate new divider lines fading in at subdivision points
- Keep existing structure, just add visual divisions
- Final state shows targetDenominator segments with (numerator * multiplier) shaded

Use SVG line elements for dividers. Animate opacity from 0 to 1 over 600ms.

Do NOT use external animation libraries - CSS transitions are sufficient for this effect.
