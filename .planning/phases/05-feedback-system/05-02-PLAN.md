```typescript
interface UseHintsReturn {
  currentLevel: HintLevel | null;  // null = no hints used yet
  hintsExhausted: boolean;         // true when level 3 used
  currentHint: string | null;      // Current hint text
  requestHint: () => void;         // Advance to next level
  resetHints: () => void;          // Reset for new problem
}

export function useHints(
  problemType: ProblemType,
  fractionA: Fraction,
  fractionB: Fraction
): UseHintsReturn
```

Behavior:
- Initial state: currentLevel=null, hintsExhausted=false, currentHint=null
- requestHint(): level 1->2->3, sets currentHint via getHint()
- After level 3: hintsExhausted=true, further requestHint() calls are no-op
- resetHints(): Returns to initial state (call on new problem)

Hook should memoize hint text to avoid recalculating on every render.
